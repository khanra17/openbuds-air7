# Artwork and screenshots

- `banner.svg` and `architecture.svg` are original project artwork, GPL-3.0-or-later. No vendor or LibrePods imagery is copied.
- `desktop-preview.png` is a screenshot of the actual application launched with `--demo`. All displayed measurements/presets are synthetic; no device/host address is rendered and no Bluetooth worker exists.
- Screenshots are manually reviewed and PNG text/EXIF metadata is rejected by the publication gate.

Reproduce the UI locally with `cargo run -p buds-desktop -- --demo`. Do not replace this image with a live-device screenshot without a full privacy review.
